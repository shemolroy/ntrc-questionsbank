# ১৮তম শিক্ষক নিবন্ধন — স্কুল পর্যায় মডেল টেস্ট (React App)

একটি React অ্যাপ, যা ১৮তম বেসরকারি শিক্ষক নিবন্ধন পরীক্ষার (স্কুল পর্যায়, ১৫ মার্চ ২০২৪) আসল ১০০টি প্রশ্ন নিয়ে তৈরি একটি ইন্টারেক্টিভ OMR-স্টাইল মডেল টেস্ট।

## চালানোর নিয়ম

```bash
npm install
npm run dev
```

তারপর ব্রাউজারে দেখানো লোকাল লিংকটি (সাধারণত `http://localhost:5173`) খুলুন।

প্রোডাকশন বিল্ড বানাতে:

```bash
npm run build
npm run preview
```

## ফাইল গঠন

```
src/
  data/questions.json   ← সব প্রশ্ন, অপশন, সঠিক উত্তর ও ব্যাখ্যা এখানে (এই ফাইলটি বদলালেই প্রশ্ন পাল্টে যাবে)
  App.jsx                ← মূল কুইজ লজিক ও UI
  index.css              ← ডিজাইন (OMR উত্তরপত্রের আদলে)
  main.jsx                ← React entry point
index.html
```

## বৈশিষ্ট্য

- বিষয়ভিত্তিক ভাগ (বাংলা, English, গণিত, সাধারণ জ্ঞান) — `questions.json`-এর `subjects` অংশে সংজ্ঞায়িত
- OMR শীটের মতো বৃত্ত-ভিত্তিক প্রশ্ন-নেভিগেটর, উত্তর দেওয়া/মার্ক করা প্রশ্ন আলাদা রঙে দেখা যায়
- কাউন্টডাউন টাইমার (৬০ মিনিট, `questions.json`-এর `durationMinutes` থেকে নিয়ন্ত্রিত)
- জমা দেওয়ার পর মোট স্কোর ও বিষয়ভিত্তিক ব্রেকডাউন

## নতুন প্রশ্ন যোগ করা

`src/data/questions.json`-এ প্রতিটি প্রশ্ন এই আকারে থাকে:

```json
{
  "id": 101,
  "prompt": "প্রশ্নের লেখা",
  "options": [
    {"id":"a","text":"অপশন ১"},
    {"id":"b","text":"অপশন ২"},
    {"id":"c","text":"অপশন ৩"},
    {"id":"d","text":"অপশন ৪"}
  ],
  "answer": "b",
  "explanation": "কেন এটি সঠিক তার ব্যাখ্যা"
}
```

নতুন `id` কোন বিষয়ের রেঞ্জে পড়বে তা `subjects` অংশের `range` আপডেট করে ঠিক করে দিন।
